# Generators
Generates random passwords of 12 randomized characters.

## Password Generator

### Usage
```bash
python generator.py   
```

## Passphrase generator

```bash
python passphrasegen.py
```

For clarity and transparency, the initial codes for both were generated with AI. As well, credit where credit is due. I used diceware (https://pypi.org/project/diceware/) and diceware as a concept (https://theworld.com/~reinhold/diceware.html)as a reference for the project, and I used EFF wordlist (https://www.eff.org/dice) and the list is created by Joseph Bonneau. If I attributed incorrectly, please let me know.
